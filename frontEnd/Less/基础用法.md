# less中基础操作
#less

在vue3项目中集成less
```shell
npm install -D less less-loader
# 或者
yarn add -D less less-loader
```
之后直接在`<style scoped lang="less">`
## 1.变量定义

使用`@`+变量名可以在less 中定义变量，可以像其他语言一样通过这种方式在文件中调用

```less
@primary=#333
.body{
	color: @primary;
}
```

## 2.Minix

混淆，可以在同一代码块中混合使用类选择起和id选择器。

```less
.border-radius(@radius) {
	-xxx: @radius;
}
#head {
	.border-radius(100px);
}

```

## 3.嵌套规则

1. 支持元素嵌套

```less
#head {
	color: black;
	.navigation{
		font-size: 16px;
	}
	...
}	
```

2. 伪类和伪元素

由于伪类在css中使用“:”（冒号）来引用的，而“:”（冒号）在less是用来属性和变量赋值的特殊符号，所以less给出了一个新的策略“&”符号。
```less
a {
	color: blue;
	&: hover: {color: green};
	&: active: {xxx};
	&: before: {
		content: "xxx";
		xxx
	}
}
```

3. 媒体查询


```less
@media (媒体类型) and (条件) {
  /* 代码块 */
}

.my-class {
  color: red;
  @media (min-width: 768px) and (max-width: 1024px) {
    color: blue;
  }
}
//解释：my-class元素在屏幕宽度为768px - 1024px之间将颜色改为blue
```

## 4.算术运算

1. Less支持对数字、颜色等属性的算术运算

```less
//四则运算
@width: 100px;
@height: @width /2;

//百分比
@percentage: 50%
@width: @percentage / 2;
```

2. 优先级

less中的算术运算也是符合常规的

```less
@a: 10px;
@b: 20px;
@c: 30px;
.example{
	width: (@a + @b)*@c /2;
}
```

## 5.函数

1. 内置函数
	- 颜色函数
		```less
		color(@argu);
		lighten(@color,@amount); //变亮
		darken(@color,@amount); //变暗
		spin(@color,@amount); //改变色调
		```
	- 字符串函数
		```less
		replace(@string,@regex,@replacement) //按正则进行替换
		```
	- 数字函数
		```less
		round() //4舍5入
		ceil() //向上取整
		floor() //向下取整
		sqrt() //开根号
		pow() //幂运算
		mod() //求余
		```
	- 其他函数
		```less
		iscolor(),isnumber(),isstring(),isuid(),iskeyword()
		```
2. 自定义函数
less中也是支持定义函数

```less
//基本定义
name(@argu){
	@return : xxx
	return @return;
}

// 内置函数使用
@baseColor: #3498db; 
.button { 
	background-color: darken(@baseColor, 10%); 
	color: lighten(@baseColor, 30%);
}

// 自定义函数
.button{
	color: name(@argu);
}
```
