# 进阶用法

## 1.命名空间和访问器

less支持将一部分样式进行封装
```less
#bundle {
	.button {
		display: block;
		border: 1px solid black;
		background-color: grey; 
		&:hover { background-color: white; }
	}
}

.body {
	#bundle.button();
	//当然还可以写成#bundle > .button
}

```


## 2.映射

1. 定义映射
```less
@colors: { 
	primary: #3498db; 
	secondary: #2ecc71; 
	tertiary: #e74c3c; 
};
//可以通过中括号还访问
.button { background-color: @colors[primary]; }
```

2. 嵌套映射


```less
//这里定义了多级map
@theme: { 
	colors: { 
		primary: #3498db; 
		secondary: #2ecc71; 
	}; 
		fonts: { 
			base: 'Helvetica, Arial, sans-serif'; 
			heading: 'Georgia, serif'; 
		}; 
};
//多级中括号来访问
.body { 
	font-family: @theme[fonts][base]; 
	color: @theme[colors][primary]; 
}
```
